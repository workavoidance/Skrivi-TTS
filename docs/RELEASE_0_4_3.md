# Skrivi Lytt 0.4.3 — Test release

A clearer reading interface, consistent with Skrivi Snakk.

- A short first-run introduction explains reading selected text anywhere and reading a screen region.
- Current shortcuts are prominent; shortcut changes use a separate, cancellable capture dialog.
- Settings and the reader fit smaller windows; scrolling over controls no longer changes their values.
- A simpler main screen keeps audio saving and screen-region reading, without the sample button or model-routing detail.
- Consistent Privacy/About screens and simpler installer licence information.

Use **Skrivi-Lytt-0.4.3-windows-x64-setup.exe** for normal installation. Quit the existing tray reader first. The full installer includes the English and Bokmål voices, signed engines and OCR. Existing models, settings and saved audio are preserved. The runtime ZIP is a build dependency, not an installer. The MSIX is for Microsoft Store submission; availability here does not imply Store certification.

These are the exact signed files approved after PC testing, built from bc84d5fdd687ed745df37799775f1a8bd319350c in https://github.com/workavoidance/Skrivi-STT/actions/runs/35537490895. Signatures, checksums, both speech engines and installer preservation checks passed.
